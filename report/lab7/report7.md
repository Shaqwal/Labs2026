# Цель работы

Освоить на практике применение режима однократного гаммирования.

# Задание

1. Разработать приложение, позволяющее шифровать и дешифровать данные в режиме однократного гаммирования.
2. Определить вид шифротекста при известном ключе и известном открытом тексте («С Новым Годом, друзья!»).
3. Определить ключ, с помощью которого шифротекст может быть преобразован в заданный фрагмент открытого текста.

# Теоретическое введение

Гаммирование представляет собой наложение на открытые или зашифрованные данные последовательности элементов с помощью операции сложения по модулю 2 (XOR). Метод является симметричным, так как шифрование и расшифрование выполняются одинаково. К. Шеннон доказал абсолютную стойкость шифра при выполнении необходимых и достаточных условий: полная случайность ключа, равенство длин ключа и открытого текста, а также однократное использование ключа.

# Выполнение лабораторной работы

1. Мы написали скрипт на языке Python для реализации побайтового шифрования и расшифрования методом XOR.
2. Задали открытый текст $P =$ `С Новым Годом, друзья!` и подобрали/сгенерировали случайный ключ $K$ соответствующей длины в шестнадцатеричном формате.
3. С помощью операции XOR получили зашифрованное сообщение $C_i = P_i \oplus K_i$.
4. Выполнили обратную процедуру расшифрования и убедились в корректности восстановления исходного текста. Сделали снимки экрана консоли с результатами выполнения программы.
